<h3 align="center">Featured projects:</h3>
<div align="center">

**[multi-agent-career-simulator](https://github.com/gabbenick/multi-agent-career-simulator)** — LLM multi-agent system (Thinker → Executor → Judge) that reads natural-language rules and simulates public-servant career progression.

**[artigo-deeplake](https://github.com/gabbenick/artigo-deeplake)** — Code for my first-author paper (ERBASE 2025): a Deep Learning + Data Lake architecture for medical image retrieval.

**[informal-settlement-detection-maceio](https://github.com/gabbenick/informal-settlement-detection-maceio)** — Supervised detection of informal settlements in Sentinel-2 imagery with Random Forest (Metropolitan Region of Maceió).

**[despacho-otimo-turbinas](https://github.com/gabbenick/despacho-otimo-turbinas)** — Optimal flow dispatch across three hydro turbines using Lagrange multipliers and KKT conditions.
